# Slots Assets

Drop your slot images in this folder using these exact names:

- `btc.png`
- `usdt.png`
- `doge.png`
- `xrp.png`
- `sol.png`
- `scatter.png`
- `wild.png`
- `eth.png`
- `bg.png` (game background)

Notes:
- PNG is currently expected by the page (`/assets/<name>.png`).
- If a symbol image is missing, the game automatically falls back to the built-in styled icon for that symbol.
