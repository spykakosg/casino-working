# Plinko Assets

Place optional artwork files here to skin the Plinko page.

## Supported files

- `bg.jpg` (main game background behind board)
- `promo.png` (right-side promo card image)
- `logo.png` (future custom logo overlay, optional)
- `board-frame.png` (future board frame overlay, optional)
- `peg.png` (future peg sprite, optional)
- `ball.png` (future ball sprite, optional)

If `bg.jpg` or `promo.png` are missing, the page still works with gradient fallbacks.
